⚡ 重大事件摘要


美國財政部外國資產控制辦公室（OFAC）於今日（2026年9月4日）進一步落實針對俄羅斯與伊朗規避制裁航運網絡的審查。隨著 P&I 停保進入第2天，西方主流保險機構對「影子船隊（Shadow Fleet）」的排查力度顯著升級。今日市場傳出多間非西方保險公司因面臨二級制裁風險，正重新評估其承保政策，導致灰色油輪的合規與再保險成本急劇飆升。

二、P&I 四階段


目前全球原油航運市場正處於 「階段二：保險終止與影子船隊轉移」。隨著 OFAC 今日更新制裁指引，非西方（如俄羅斯、中國或印度本土）保險機構的承保能力面臨再融資與合規瓶頸，灰色船隊正加速尋求更隱蔽的轉移管道。
